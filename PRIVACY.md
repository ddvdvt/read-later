# Политика конфиденциальности «Прочитать позже»

_Дата: 26.10.2026_

## Какие данные обрабатываются

- **Статьи, которые вы сохраняете.** После вашего действия (значок расширения, пункт контекстного меню, `Alt+Shift+S`) расширение читает открытую вкладку: текст статьи, заголовок, автора, название сайта, дату, адрес страницы и, если это включено в настройках, картинки статьи.
- **Ваши действия с библиотекой:** теги, избранное, архив, позиция чтения, выделения и заметки.
- **Настройки:** шрифт, тема, напоминания о резервной копии и т. п.
- **Файлы импорта** (экспорт другого сервиса, закладки, список ссылок) читаются прямо в браузере, только когда вы их выбираете.

## Где хранятся данные

Только локально, в вашем браузере: IndexedDB и `chrome.storage.local` расширения. Данные не синхронизируются и не передаются ни автору, ни третьим лицам. Аккаунта нет.

## Какие сетевые запросы делает расширение

Только те, которые вы явно запросили:

- **Картинки статьи** при сохранении скачиваются с сайта статьи, чтобы читать её без интернета (можно отключить в настройках).
- **«Загрузить текст»** для статей, сохранённых как ссылки (например, после импорта): расширение скачивает эти страницы с их сайтов. Для этого Chrome спрашивает разрешение на доступ к этим сайтам; разрешение снимается сразу после загрузки. Запросы отправляются без cookies.
- **«Сохранить выбранные вкладки»**: Chrome спрашивает доступ к сайтам, чтобы прочитать текст этих вкладок; доступ снимается сразу после сохранения.
- В читалке картинки, которые не были сохранены, по умолчанию загружаются с сайта-источника (это можно выключить: «Показывать картинки с сайта»). Ссылки открываются без передачи адреса читалки (`noreferrer`).

Нет серверов автора, аналитики, рекламы, телеметрии и удалённого кода.

## Закладки браузера

Доступ к закладкам запрашивается только при импорте из закладок, используется для чтения выбранной папки и снимается сразу после.

## Страницы сайта автора

После установки расширение один раз открывает вкладку с короткой инструкцией на сайте автора, а после удаления браузер открывает страницу с вопросом «почему удалили?». Это обычные статические страницы: расширение не добавляет к их адресам никаких данных или идентификаторов и ничего им не передаёт.

## Экспорт и удаление

- Резервная копия (JSON), закладки (HTML) и Markdown (ZIP) создаются в браузере и сохраняются туда, куда вы укажете. Автоматических выгрузок нет.
- Удалённые статьи 30 дней лежат в корзине, затем удаляются насовсем. Корзину можно очистить раньше.
- Удалить всё: настройки → «Удалить все статьи и настройки», либо удалить расширение.
