Импорт

Перенесите сохранённые статьи из другого сервиса. Подходят файлы экспорта Pocket (HTML или CSV), Omnivore (ZIP), Instapaper (CSV), файл закладок любого браузера (HTML), список ссылок (TXT) и резервная копия этого расширения (JSON).

Перетащите файл сюда или нажмите, чтобы выбрать .html · .csv · .zip · .json · .txt
Вставить список ссылок
Из закладок браузера

Chrome спросит доступ к закладкам — только для чтения выбранной папки. После импорта доступ будет снят.

Экспорт и резервная копия

Все статьи хранятся только в этом браузере. Сохраняйте копию — её можно восстановить здесь же, в разделе «Импорт», на этом или другом компьютере.

JSON

Полная копия без потерь: тексты, теги, выделения, заметки, позиция чтения, настройки.

HTML

Файл закладок: открывается в любом браузере и импортируется в большинство сервисов.

Markdown

ZIP: по файлу на статью с текстом и выделениями — для Obsidian, Logseq и любых заметок.

Расширение никуда не загружает копии: файл сохраняется только туда, куда скажете вы.

О расширении

Сохраняйте статьи, чтобы прочитать их позже — даже без интернета. Значок на панели, пункт в контекстном меню или Alt+Shift+S.

Без аккаунта, рекламы и аналитики. Статьи, выделения и настройки хранятся только в этом браузере и никуда не отправляются.
