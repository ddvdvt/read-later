# Прочитать позже — статьи офлайн, без аккаунта

Расширение для Chrome/Edge и Firefox (Manifest V3): сохраняет статьи, чтобы прочитать их позже — в том числе без интернета. Текст статьи, выделения и заметки хранятся **только в вашем браузере**: нет аккаунта, сервера, рекламы и аналитики. Библиотеку легко забрать с собой: импорт из других read-it-later сервисов и экспорт в JSON, HTML и Markdown.

Ниша: Pocket и Omnivore закрылись, людям нужно куда-то перенести сохранённые статьи — и желательно туда, откуда их никто не отнимет.

## Что умеет

**Сохранение**
- Текущая страница — значок на панели, `Alt+Shift+S` или пункт «Сохранить страницу для чтения» в контекстном меню.
- Ссылка — пункт «Сохранить ссылку для чтения» в контекстном меню ссылки (сохраняется как ссылка, текст загружается потом).
- Несколько вкладок сразу — выделите вкладки (Ctrl/Shift+клик) и нажмите в окне расширения «Сохранить выбранные вкладки».
- Чистый текст статьи (Mozilla Readability), заголовок, автор, сайт, дата, главная картинка, время чтения. Картинки статьи сохраняются для офлайн-чтения (настройка, лимит на статью).
- Повторное сохранение той же страницы обновляет текст и не создаёт дубликат (адреса сравниваются без `utm_*`, `www`, якорей).

**Библиотека**
- Разделы: непрочитанное, избранное, с выделениями, архив, все, корзина; теги со счётчиками; «без тегов».
- Полнотекстовый поиск по локальному индексу (по префиксам слов, ё = е), сортировка, список или карточки.
- Массовые действия: архив, избранное, теги, загрузка текста, корзина. Отмена последнего действия.
- Клавиатура: `j`/`k`, `Enter`, `x`, `Shift+A`, `e`, `f`, `t`, `Delete`, `/`, `g u|a|f`, `?` — справка.

**Читалка**
- Шрифт (serif/sans/mono/системный), размер, интервал, ширина, тема (авто/светлая/сепия/тёмная), выравнивание.
- Позиция чтения сохраняется для каждой статьи; «Прочитано — в архив» (или автоархив).
- Выделения четырьмя цветами и заметки; список выделений, копирование в Markdown. Привязка по цитате с контекстом — переживает повторное сохранение статьи.
- «Открыть оригинал», «Копировать как Markdown», «Загрузить текст заново».

**Импорт** (настройки → «Импорт»): Pocket (HTML и CSV), Omnivore (ZIP: метаданные, текст, выделения), Instapaper (CSV), файл закладок любого браузера, папка закладок Chrome, список ссылок, резервная копия этого расширения. Статьи без текста импортируются как ссылки; текст можно загрузить потом («Только ссылки» → «Загрузить текст»).

**Экспорт**: JSON без потерь (тексты, теги, выделения, заметки, позиция, настройки, по желанию картинки), HTML-закладки, Markdown-файлы по статье в ZIP. Напоминание о резервной копии (раз в 1/2/4 недели или никогда). Ничего никуда не загружается автоматически.

**Сохранность данных**: IndexedDB, каждая запись — одна транзакция (статья + текст + индекс + выделения + картинки). Удалённое лежит в корзине 30 дней. Предупреждение, если место заканчивается.

Чем отличается от «Сейфа вкладок» (tab-vault) того же автора: tab-vault сохраняет **сессии вкладок** (наборы ссылок), а это расширение — **статьи для чтения**: чистый текст, офлайн, выделения.

## Установка (распакованное расширение)

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное» → папка `extension/`.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `activeTab` | Прочитать текст **той вкладки**, где вы нажали значок, пункт меню или `Alt+Shift+S`. Без доступа к остальным сайтам. |
| `scripting` | Вместе с `activeTab`: запустить в этой вкладке встроенный в расширение код извлечения статьи (Readability) и показать короткое уведомление «Сохранено». |
| `storage` | Настройки (шрифт, тема, напоминания). |
| `contextMenus` | Пункты «Сохранить страницу/ссылку для чтения» и «Открыть библиотеку». |
| `unlimitedStorage` | Тексты и картинки статей лежат в IndexedDB; без этого разрешения браузер может удалить офлайн-библиотеку при нехватке места на диске. |
| `bookmarks` (необязательное) | Запрашивается только при импорте из закладок, снимается сразу после. |
| Доступ к сайтам (необязательный, `http://*/*`, `https://*/*`) | Запрашивается только в момент, когда вы просите загрузить текст для сохранённых ссылок (только их сайты) или сохранить несколько вкладок сразу. Снимается сразу после работы. |

## Приватность

Расширение не делает сетевых запросов, кроме тех, что вы явно попросили: загрузка текста сохранённой ссылки или картинок статьи с её сайта. Нет аккаунтов, аналитики, рекламы и телеметрии. Подробно — [PRIVACY.md](PRIVACY.md).

## Firefox

Сборка для Firefox делается из тех же исходников `extension/` — меняется только манифест (скрипт `scripts/firefox.mjs`):

```
npm run zip:firefox       # dist/read-later-<версия>-firefox.zip (для AMO) + распакованная сборка dist/firefox/
npm run lint:firefox      # web-ext lint по распакованной сборке
npm run test:e2e:firefox  # e2e в установленном Firefox (временный профиль, только локальные страницы)
```

**Установка для проверки:** `npm run zip:firefox` → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение…» → `dist/firefox/manifest.json`. Временное дополнение удаляется при закрытии Firefox. Данные библиотеки (IndexedDB) привязаны к внутреннему адресу дополнения — у временного дополнения он меняется при каждой установке.

**Чем отличается от Chrome:**

- Нужен Firefox **140+** (ESR 140): с этой версии есть `data_collection_permissions` — обязательное для новых дополнений на AMO поле «какие данные собираются» (у нас `none`). Для Firefox для Android — 142+.
- Фон — event page вместо service worker (тот же файл `src/background.js`); всё остальное — те же файлы.
- В манифесте Firefox задан CSP страниц расширения `script-src 'self'` — такой же, как по умолчанию, но без `upgrade-insecure-requests`, который Firefox добавляет в MV3 сам: иначе «Загрузить текст» для статей с http-сайтов и их http-картинки в читалке не работали бы.
- Скрипты извлечения статьи подключаются по путям от корня (`/vendor/Readability.js`): Firefox считает относительные пути `scripting.executeScript({ files })` от страницы, которая вызывает (раньше «Сохранить выбранные вкладки» из библиотеки в Firefox сохраняло только ссылки).
- Необязательные разрешения (доступ к сайтам, закладки) Firefox запрашивает своим окном, как Chrome; после работы расширение их снимает.
- «Изменить» у горячей клавиши в настройках открывает в Firefox about:addons → «Управление горячими клавишами» (`commands.openShortcutSettings`). `Alt+Shift+S` не занято Firefox.
- `web-ext lint`: 2 предупреждения `innerHTML` — оба внутри неизменённой Mozilla Readability (`vendor/`). Собственный код вставляет разметку только через `DOMParser` (инертный документ).
- Идентификатор дополнения: `read-later@ddvdvt.github.io`.

Тексты и ответы для AMO — [`store/amo.md`](store/amo.md).

## Разработка

```
npm install          # только playwright-core для e2e (браузер не скачивается)
npm test             # юнит-тесты lib/ (node --test)
npm run test:e2e     # Playwright + установленный Chromium, только локальные страницы
npm run zip          # dist/read-later-1.0.0.zip с проверкой архива
npm run locales      # _locales из scripts/locales.src.mjs
npm run icons        # иконки
npm run store:images # скриншоты и промо для Chrome Web Store (store/)
```

Чистая логика — `extension/lib/` (без `chrome.*`): парсер HTML, санитайзер, Markdown, поиск, выделения, импорт/экспорт, ZIP. Внешняя библиотека одна: Mozilla Readability 0.6.0 в `extension/vendor/` (Apache-2.0, лицензия рядом, код не изменён).

Ссылки на сайт автора (welcome/bye/privacy/«Другие расширения») задаются одной константой `BASE` в `extension/lib/brand.js` (сейчас заглушка) — вместе с `homepage_url` в манифесте.
